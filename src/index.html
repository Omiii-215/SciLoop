Frequently Asked Questions

The Model Context Protocol (MCP) is an open standard created by Anthropic that allows local AI tools (such as Claude Desktop, Cursor, or ChatGPT) to securely access SciLoop's real-time literature databases (Europe PMC, Crossref, arXiv) and Smart Citation analysis directly during reasoning.

Every claim generated by SciLoop is verified against live DOI and PubMed identifier (PMID) databases. Citations contain direct DOI links and real snippet excerpts extracted from peer-reviewed publications.

Instead of superficial citation counts, Smart Citations analyze citation statements within papers: Supporting confirms an empirical finding, Contrasting challenges or presents conflicting data, and Mentioning cites the work for background context.

MCP Server Tool Documentation
TOOL search_literature(query: string, limit?: number)

Queries Europe PMC, Crossref, and arXiv in parallel for relevant peer-reviewed publications and preprints.

TOOL smart_citations(doi: string)

Extracts citation statements and counts supporting, mentioning, and contrasting citation contexts.

TOOL fetch_fulltext(identifier: string)

Fetches open-access XML/PDF full-text sections, methods, and figures from Europe PMC or arXiv.

TOOL synthesize_evidence(hypothesis: string, papers: string[])

Conducts cross-study triangulation, synthesizes empirical consensus, and isolates conflicting findings.
